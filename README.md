# Daily Summary

일일 업무 내역을 자유 형식으로 입력하면 작성자와 프로젝트 기준으로 정리해 주간 보고서 Markdown을 만드는 업무보고서 자동화 앱입니다.

## 사용 흐름

| 사용자 | 경로           | 기능                                            |
| ------ | -------------- | ----------------------------------------------- |
| 작성자 | `/reports/new` | 오늘 업무와 다음 주 예정 업무 입력              |
| 관리자 | `/weekly`      | 작성자별 주간 업무 보고서 확인 및 Markdown 복사 |

## 주요 기능

| 기능          | 설명                                                            |
| ------------- | --------------------------------------------------------------- |
| 자유 입력     | 별도 양식 없이 업무 내역을 줄 단위로 입력                       |
| 정규화 저장   | 입력 원문을 저장하고 업무 항목 단위로 분리                      |
| 주간 보고서   | 작성자, 프로젝트, 이번 주 업무, 다음 주 예정 업무 표 출력       |
| Markdown 복사 | 보고서 표를 Markdown 형식으로 복사                              |
| 예외처리      | 입력값 오류, 날짜 오류, 외부 모델 호출 실패, 클립보드 실패 처리 |
| 보안 설정     | HTTPS 모델 엔드포인트 제한, 입력 길이 제한, 기본 보안 헤더 적용 |

## 실행 준비

```bash
npm install
cp .env.example .env
npm run prisma:migrate
npm run dev
```

## 검증

```bash
npm test
npm run build
```

## 환경 변수

| 이름                     | 설명                                             |
| ------------------------ | ------------------------------------------------ |
| `DATABASE_URL`           | SQLite DB 파일 경로                              |
| `GITHUB_MODELS_TOKEN`    | GitHub Models 호출 토큰                          |
| `GITHUB_MODELS_ENDPOINT` | GitHub Models 추론 API 주소. HTTPS만 허용됩니다. |
| `GITHUB_MODELS_MODEL`    | 사용할 모델 이름                                 |

`GITHUB_MODELS_TOKEN`이 없거나 모델 호출이 실패하면 줄 단위 기본 분리 방식으로 정규화합니다.
